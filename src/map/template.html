한눈에

    모듈 지도

    위에 있는 모듈이 아래에 있는 모듈을 가져다 써요. 모듈을 누르면 그 모듈과 이어진 선만 남고, 아래에 어떤 파일이 어떤 파일을 import하는지 나와요.

    흐름을 거스르는 import

    서로 물린 파일

    서로를 import해서 한 덩어리가 된 파일 묶음이에요. 컴파일 오류는 아니지만, 묶음 안의 파일 하나를 떼어 옮기거나 따로 테스트하기 어려워져요.

    다른 기능 폴더에서 가져다 쓰는 것

    다른 모듈에서 그 모듈의 화면도 provider도 아닌 것을 가져오는 import예요(저장소 설정의 openToOtherModules에 맞지 않는 파일). 리뷰에서 짚을 후보를 파일 이름과 선언으로 추린 목록이라, 판정은 아니고 살펴볼 곳이에요.

    외부 SDK가 닿는 파일

    외부 패키지를 직접 import하는 파일이에요. 적을수록 바꾸거나 가짜로 갈아 끼우기 쉬워요.

    파일 찾아보기

    크고, 자주 바뀌고, 여러 곳에서 쓰이는 파일이 손볼 때 조심할 곳이에요. 열 이름을 누르면 그 값으로 정렬해요.
